# Page instructions

Read [CLAUDE.md](CLAUDE.md) and [../../CLAUDE.md](../../CLAUDE.md) before
editing pages. They define page composition, hub/tab boundaries, shared
primitives, mobile behavior, and interaction tests.

Read the relevant backend app's `CLAUDE.md` when changing domain behavior.
Keep page-specific components beside their owning page, and promote them to
shared components only when another page uses them. Preserve the existing
role-aware navigation and API request contracts.
